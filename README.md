# JavaScript Todo List

Веб-приложение для создания и управления списком задач. Пользователь может добавлять задачи, отмечать их как выполненные, редактировать и удалять, а данные сохраняются после обновления страницы.

Проект создан на основе учебного проекта JavaScript Todo List и доработан для выполнения практической работы.

## Реализованные возможности

- добавление новых задач;
- редактирование задач;
- отметка задачи как выполненной;
- удаление задач;
- фильтрация задач;
- сохранение данных после обновления страницы;
- подсчёт текущих задач;
- автоматическое тестирование основных функций.

## Технологии

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Node.js
- npm
- Tape
- JSDOM

Backend и внешняя база данных не используются. Данные хранятся локально в браузере с помощью LocalStorage.
